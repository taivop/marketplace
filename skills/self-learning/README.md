# self-learning

Structured self-coaching for work-relevant skill growth: 2-3 month goals broken into 1-2 week themes, daily active-practice sessions with review metrics, weekly reviews, and enforced accountability. State is tracked as markdown files in a workspace directory you own (default `~/self-learning/`).

Based on a startup-era coaching method ("Karu"): most people don't fail at learning for lack of content — they fail because learning never turns into concrete daily practice with sustained accountability.
