# coach

[![Deploy on MindPal](https://mindpal.space/badges/deploy-on-mindpal.svg)](https://mindpal.space/skills/thinking-partner-coach?utm_source=github&utm_medium=readme_button)

Neutral thinking partner: Socratic coaching conversations that help you think a fuzzy topic through yourself.

Note from the author: this works best at **low reasoning effort** so replies come quickly and the conversation stays fluid. Reasoning effort is a harness setting the model cannot change itself — set it yourself (e.g. via `/model` effort selection in Claude Code) before a session.
